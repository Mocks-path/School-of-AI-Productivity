AI Planning & Task Management — turn a fuzzy goal into a plan you can defend

Four hands-on activities. Sort the moves that take a goal from scope to timeline, assemble a planning prompt block by block, run the estimate clinic on three suspiciously optimistic plans, and drill the discipline that keeps you honest — because a plan AI can generate in ten seconds is a draft, not a commitment.

Progress
1

Match each move to the right planning stage

A plan isn't one big leap — it's a sequence: define the scope, break it into a work-breakdown structure (WBS), estimate the tasks, then wire up dependencies and a timeline. AI can accelerate every stage, but only if you know which stage you're in. Study the three stages below, then drag each planning move into the stage it belongs to. Guess freely — wrong answers explain themselves on hover.

S

Scope & break down

"Decide what's in, what's out, and split the work into chunks." The foundation everything else rests on.

  • Write the goal + what's explicitly out of scope
  • Draft a WBS: phases → deliverables → tasks
  • Name constraints: deadline, budget, team size
E

Estimate the work

"Put a size on each task." Answers "how long" and "how much" — and where the planning fallacy hides.

  • Estimate effort per task (hours or days)
  • Add buffers for the unknowns you can't list yet
  • Sanity-check against a similar past project
D

Sequence & schedule

"Wire the tasks together and lay them on a calendar." Turns a task list into a real timeline.

  • Map dependencies: what blocks what
  • Find the critical path — the longest chain
  • Build the Gantt / timeline with milestones

The own-the-plan quiz — AI drafts, you decide

AI produces a plan that looks complete. Looking complete is not the same as being realistic. This quiz drills the single most important habit in AI-assisted planning: treat the AI plan as a first draft and pressure-test it against reality before you commit. Five situations, one honest answer each — the misconceptions are where the real learning is.

Quick reflect — make it stick
